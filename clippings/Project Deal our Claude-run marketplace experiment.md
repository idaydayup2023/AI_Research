# Project Deal: our Claude-run marketplace experiment

## 原文信息

- 原文：<https://www.anthropic.com/features/project-deal>
- 发布时间：2026-04-24
- 发布方：Anthropic

## 核心提取

Project Deal 是 Anthropic 做的一次 Claude-run marketplace 实验：69 名员工把自己的买卖偏好交给 Claude 代理，agents 彼此发布、谈判、成交，最后人类执行真实物品交换。实验产生了 186 笔交易，总交易额略高于 4000 美元。

最值得关注的是平行实验：参与者由不同 Claude 模型代表。更强的模型给用户争取到更好的客观结果，但使用较弱模型的人并没有明显意识到自己吃亏。这对未来 agent-to-agent commerce 很重要：当代理替用户交易时，模型能力差距可能变成真实经济差距，而用户未必能感知。

## 中文译读

### 一、Agent 会进入交易场景

这不是一个普通 demo，因为它把 agent 放进了多方博弈和真实利益交换里。Agent 不只是帮你写文档，而是代表你谈条件、做取舍、影响结果。

### 二、模型能力差距会转化为经济差距

更强模型能更好地谈判、识别机会、保护用户利益。弱模型用户可能并不知道自己被代表得更差。这会带来新的产品伦理和市场公平问题。

### 三、用户感知不等于实际效果

实验中，弱模型用户不一定察觉自己处于劣势。这提醒 Agent 产品不能只靠满意度评估，还要看客观 outcome。

## 可复用观点

- Agent-to-agent commerce 会让模型能力差距直接进入经济结果。
- 用户主观满意度不足以衡量代理质量。
- 未来代理产品可能需要 outcome audit、能力披露和争议处理机制。
