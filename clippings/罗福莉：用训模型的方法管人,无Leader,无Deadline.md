# 罗福莉：用训模型的方法管人

两个月前，罗福莉觉得 AGI 至少还要两年以上。

两个月后的这场访谈里，她改口了：两年以内。她说目前 AGI 的进度大概走到了 20%，年底有可能到 60% 到 70%。两个月，判断就翻了一倍。

她不是在随便说。她训过 DeepSeek V3，目前在主导小米 MiMo 系列模型。她对中国和美国顶尖模型的代差给了一个数字：两三个月。不是两三年。她的判断依据很具体：国内已经有好几家公司具备 1T 以上的基座模型，如果反应速度足够快，追上当代 Claude Opus 的水平只需要两三个月。她特别强调了一点：不是说两三个月后能追上两三个月后的 Claude，而是能追上"当代的"Claude。决定这个速度的不是技术储备，是团队的研究敏捷度，以及能不能拥抱新的范式来做研究。

然后她说了一句在学术圈可能会引起争议的话：**「发论文？越少越好。」** 她现在不看学术会议的论文了。信息来源自迭代，自实验，自跟人沟通。

AGI 两年内。代差两三个月。不看论文。这三个判断来自同一个人。

但至少在 AI 研究这样的前沿领域，传统企业那套层级管理、经验优先、论文衡量的方式，正在变得不太管用了。

> 在这个速度下，什么样的人和组织能跟上？

## 层级制度的假设「很奇怪」

罗福莉在小米带了一个大概 100 人的团队。但真正投入到一代模型迭代的，只有二三十个人。训一个 1T 参数的模型需要多大的团队？她说：「很小。」训练本身几个人，数据几个人，加上基础设施团队，核心链路就这么多人。

这个团队没有组的划分。没有预训练组、后训练组的区分。为什么？因为很多人对两个方向都感兴趣，如果你把组划分得很清晰，「其实是在扼杀一部分的创造力，或者说扼杀它未来的成长空间」。

没有组也就没有 leader。有推动项目往前走的人，但这个人「并不对参与这个项目的人有绝对的控制权」。没有职级，没有 deadline。「我们觉得模型训好了我们再发。」

然后她说了一句话：**「层级默认这个层级上的人应该有更强的超越所有人的一个智能。这个界定非常奇怪。」**

想一下这句话在说什么。层级制度背后的假设是：越往上的人掌握越多信息、做越好的判断。这个假设在信息稀缺、变化缓慢的时代可能是对的。但在 Agent 时代，信息密度爆炸，变化速度以周为单位，这个假设的两个前提条件都不成立了。而代差只有两三个月这件事本身就说明了一个问题：在这种速度下，层级越多，决策链越长，反应就越慢。你的竞争对手可能只有二三十个人，但他们比你快两个月做出同样的东西。

作为对比：DeepSeek 整个公司大约 200 人，Anthropic 有数千名员工。做的是同一级别的竞争。团队规模差了十几倍甚至更多，输出并没有差十几倍。

有人会说：这是前沿实验室，普通公司不能这样。这没错。但管理范式的演化规律一直是从边缘到中心。今天 AI 研究团队在试验的组织方式，很可能就是三年后所有知识工作团队的组织方式。层级不是唯一的协调机制，而在变化足够快的时候，它甚至可能是最差的那个。

## 不靠层级靠什么

如果层级不行，那靠什么管理一个团队？罗福莉的答案可以拆成三个关键词：**热爱、环境、蒸馏**。

**先说热爱。** 她说这话不是在灌鸡汤。她有一个非常具体的操作。春节刚过，OpenClaw 刚火起来，她在团队群里下了一个指令：如果第二天 OpenClaw 的对话次数不超过 100 轮的人，可以直接 quit。

这听起来很极端。但她解释了背后的逻辑：她不会真的去考核谁对话了多少轮。「我不会去考核，我也不会第二天去检查。我只在乎你有没有真的去用这个动作。」目的不是考核结果，是**创造体验**。她提前买了几台 Mac Mini，部署好环境，把人拉到不同方向的飞书群里。让大家在群里玩。当你看到别人用 OpenClaw 做成了一件你没想到的事，你自己的想象力就被激发了。这个管理方式不是「你必须做到什么」，而是「我先让你体验到这个东西有多好玩，剩下的你自己会去做」。

**再说环境。** 这是我在这个访谈里听到的最有意思的跨界类比。罗福莉用了训模型的术语来评估人才，而且这不是文学修辞，这是她真实的人才筛选标准。

她说：「**我只在乎他的初始化 checkpoint 的上限高不高。但我不太在乎他目前已经被 supervised learning 过后的那个点的状态。**」

解释一下这两个概念。**Checkpoint（检查点）** 是训练模型时保存下来的模型状态。罗福莉借这个词强调的，是一个人在新环境里的潜力上限。**Supervised Learning（监督学习）** 是用标注好的数据去教模型的过程，教完之后会形成一个相对确定的当前状态。

她在说什么？一个训大模型的人，开始用训练模型的框架来审视人。传统的招聘看简历，看你学了什么学校、做过什么项目、发了什么论文。这些都是 supervised learning 之后的状态，是被教出来的。但罗福莉看的是另一个维度：如果把你放进一个全新的环境，你最终能学到什么程度？这个天花板才是她在意的。

以我个人的理解，她的逻辑大致是这样的：在 Agent 时代，具体的技能一两个月就能学会，慢的话三四个月。你今天不会写 RL 的 reward function，放到这个环境里，身边的人每天都在讨论这个东西，你很快就会了。所以技能本身不稀缺。稀缺的是一个人在面对全新领域时能走多高的那个上限。

所以她现在反而倾向招更年轻的人。「我们会去招大二大三的人。因为他们的灵活性和适应程度都感觉没有被污染，天然更接纳。」这些人的 supervised 后状态可能很低，没做过大项目，没发过论文。但她赌的是 checkpoint 上限。

**最后说蒸馏。** 这也是一个训模型的术语。她用了一个叫 **MOPD（Multi-Teacher On-Policy Distillation，多教师在线策略蒸馏）** 的概念来描述团队的协作方式。

在模型训练里，蒸馏是一种让小模型学习大模型精华的技术：大模型（老师）不只是把答案告诉小模型（学生），也可以把输出分布、偏好、奖励信号或解题轨迹迁移过去。多教师蒸馏就是同时从很多个老师那里学，每个老师有不同的强项。

罗福莉把这个概念直接搬到了团队管理上：「就是互相的蒸馏，我蒸馏你的长处，你蒸馏我的长处。」想象一下这个画面：传统团队像一个教室，一个老师在讲台上讲，所有人在下面听。她的团队更像一桌人在打牌。每个人手里的牌不一样，你出了一手好牌，我看到了，学会了这个打法；我换了一种组合方式，你又从中提取到了新的思路。没有谁是固定的老师，每个人都在从其他人的"出牌"里提取自己需要的东西。

这也是为什么她不按训练阶段给团队分组。做预训练的人自然流向后训练，做后训练的人关注强化学习。不是被安排的，是大家自然而然发生的。做预训练的人天然关注数据多样性，这种多样性视角在后训练阶段反而是稀缺优势。如果把人按阶段硬分到不同的组里，这种跨阶段的蒸馏就断了。

## 群体智能是乘积，不是加法

但罗福莉让我觉得最有意思的判断不是关于她自己团队的。是她关于人类整体协作方式的思考。

春节后的那几天，团队在飞书群里的状态她形容为「躁动」。近 100 个人在群里疯狂分享自己用 OpenClaw 的发现。十分钟不看消息就 999+。「一点都不苦，一点都不残酷，就真的很好玩。」

在这个过程中她观察到一件事：**「个人的想象力真的是局限的。但是当你看到别人用 OpenClaw 居然能干成这个事情的时候，你就会激发你自己的想象力。大家的想象力是一个乘积的作用。」**

什么叫乘积？想象一下那个飞书群里发生的事：有人发了一条消息说，「我让 OpenClaw 修一个 bug，它自己跑去查了 git log」。另一个人看到后想到：「那是不是可以让它直接用 git bisect 定位问题根源？」第三个人接上来：「等等，如果它能读 git log，那它能不能直接读 PR review 的评论，然后自己总结出代码规范？」三条消息，十分钟，一个新的使用范式就诞生了。第三个人的想法不是前两个想法的简单叠加，它是前两个想法碰撞之后涌现出来的全新方向。这就是乘积。

然后效率就出来了。「我们基本上可能在三四周的时间做完了以前可能三四十周的时间才能做到的事情。在研究上。」Agent 加速了这个过程，因为你可以把十个 idea 交给不同的 subagent 同时验证，它们还能交叉验证。「你无非烧很多 token，你就能验证你这个研究的想法 OK 不 OK、work 不 work。」

她还指出了一个更大的变化：2026 年的标志性节点是，**不再只是算法工程师在提升智能水平了**。所有懂写代码的人，不管是在写 Skills、改 Agent 框架还是设计研究范式，都在参与这件事。她觉得这是 AGI 到来的前兆。不是某个实验室的突破，是全人类的群体智慧在加速收敛。

## 从建模价格到做符合价值观的事

采访快结束的时候，主持人问她：过去半年意味着什么？她没有聊技术。她说：「我感觉每天可能都在否定昨天的自己。不管是做事的方式上，还是对事情未来的一些判断上，我基本上都在一直去否定。」

然后她讲了自己的一个转变。做量化交易的时候，她有一句给自己力量的话：「总有方式去建模价格。」价格是清晰的 reward。预测准了就赚钱，预测错了就亏钱。反馈明确，循环清晰。

但做大模型之后，reward 不清晰了。你不知道什么是「好模型」的终极标准，目标在变化，范式在变化。这个时候怎么办？

> 她说：「我应该做当下符合我价值观的事情。这个事情一定是要对更多人产生价值的，一定要是更有意义的事情。」

然后她补了一句：「如果我们创造大模型的这一批人，如果说没有这样一个内驱力，而是说我要做一个破坏的东西，那么我估计最后会非常危险。」

她还用了一个训模型的术语来描述自己处理压力的方式。她说自己的脑子是一个 **Sliding Window Attention（滑动窗口注意力）**。这个概念在大模型里大致是这样工作的：模型在处理文本时，每个位置优先关注最近一段"窗口"里的信息，较远信息的直接访问会被限制，或者依赖其他层和机制继续传递。就像手机屏幕上的消息通知：新的推送来了，旧的就自动被挤出视野，你不需要手动去删除它。

她说的是：「我忘得非常快。哪怕有压力，快的话一两个小时就过了，慢的话一天就过了。」但按我的理解，这有一个关键前提：不是压力自己消失了，而是第二天必须有新的、密度足够高的体验涌进来，把旧的 context 从窗口里挤出去。这也许能解释为什么她的团队需要保持那么高的迭代频率：高频迭代不只是为了产出，也是在为团队里的每个人制造「新 context」，让昨天的焦虑自然滑出窗口。

## 为什么旧范式还在流行

层级、经验、论文。这三样东西有一个共同特征：**好衡量**。职级高不高，一看组织架构图就知道。工作年限多不多，一看简历就知道。论文发了几篇，一查 Google Scholar 就知道。层级制度给了每个人一个位置，让组织看起来有序，让人才筛选看起来有据可依。

但「看起来有序」和「真正高效」是两件事。在信息稀缺、变化缓慢的年代，这套逻辑是管用的。经验需要时间积累，信息需要层级传递，论文也确实是研究能力的合理代理指标。但当变化速度以周为单位、信息密度爆炸、技能一两个月就能习得的时候，这三个前提条件都在松动。好衡量的东西不一定是重要的东西。

回到上一篇的结尾。我说罗福莉的三天顿悟「不是关于 OpenClaw 的，是关于一个更大的事情：AI 的范式已经变了。」

现在我想补充一句：范式变的不只是技术。变的是人怎么组织，怎么选人，怎么成长，怎么在这个加速度里找到自己的意义。

如果你在管团队，问自己一个问题：你的层级是在传递信息，还是在阻塞信息？如果一个决策需要经过三层审批才能落地，而你的竞争对手只有二三十个人、没有审批流程，那他们已经在这段时间里完成了一轮迭代。

如果你在选下一份工作，看环境，不看 title。你的成长速度取决于身边的人是谁、信息密度有多高、试错的自由度有多大。

如果你在评估自己的价值，看 checkpoint 上限，不看 supervised 后的状态。你今天会什么不重要，重要的是把你放进一个全新的领域，你能走多高。

这一整套东西，就是上一篇结尾我说的「一整套我没想到的东西」。
